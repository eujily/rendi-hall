# ADR-001: Визуальный стиль — toon-3D на языке бренда Rendi

**Status:** Accepted
**Date:** 2026-10-09
**Deciders:** Жека

## Context

Нужен изометрический мир «в духе Stardew Valley» для портфолио-концепта Rendi.
Бренд (apprendi.io) — плоская векторная иллюстрация: пастельные заливки без
градиентов, чёрный «рукописный» контур, жёсткая сдвинутая серо-лиловая тень
без блюра, маскот Randy — фиолетовая 8-лепестковая клякса с линейными
конечностями. Stardew — пиксель-арт. Эти языки конфликтуют.

Цель концепта — показать заказчику «мы поняли ваш бренд и умеем в 3D».

## Decision

Toon-3D: ортографическая изометрическая камера, плоские (unlit/toon)
материалы бренд-цветов, чёрный контур (inverted hull), жёсткие тени-декали
со сдвигом. От Stardew берём уют, масштаб и населённость, не пиксели.

## Options Considered

### Option A: Toon-3D в языке Rendi
| Dimension | Assessment |
|---|---|
| Complexity | Med — один общий kit (материал + контур + тень) |
| Brand fit | High |
| Параллелизуемость | High — вся геометрия процедурная, без ассет-пайплайна |

**Pros:** бренд переносится в новое измерение; Randy узнаваем; без внешних ассетов.
**Cons:** «Stardew» читается через атмосферу, а не через узнаваемую технику.

### Option B: Буквальный пиксель-арт (low-res render + nearest upscale)
| Dimension | Assessment |
|---|---|
| Complexity | Med |
| Brand fit | Low — линейные конечности Randy теряются в пикселях |

**Pros:** мгновенно узнаваемо как Stardew. **Cons:** спорит с брендом; посыл «мы скопировали игру».

### Option C: 2.5D — 3D-здания + SVG-спрайты персонажей
| Dimension | Assessment |
|---|---|
| Complexity | Low–Med |
| Brand fit | High для персонажа, Low для сцены в целом |

**Pros:** маскот 1:1 из их SVG. **Cons:** спрайты на изометрии выглядят вклейкой; кукольная ходьба.

## Trade-off Analysis

A жертвует буквальной узнаваемостью Stardew ради бренд-консистентности —
для питча заказчику это правильный обмен: оценивают понимание их бренда.

## Consequences

- Проще: единый `kit/toon.js` даёт стиль всем агентам одинаково.
- Сложнее: контур удваивает draw calls — следить за бюджетом (см. spec §Perf).
- Пересмотреть: если заказчик захочет «больше Stardew» — пикселизация как пост-эффект поверх A добавляется без переделки сцены.
